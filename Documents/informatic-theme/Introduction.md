# Introduction

Standards for installable **remote themes** in the **Informatic theme editor**.

**Informatic themes** power **content / information websites** — marketing sites, company pages, knowledge hubs, landing pages — that display copy, media, articles, and forms. They are **not** e-commerce storefronts (no product catalog, collections, cart, or checkout).

This file is the **starting menu**. Details live in the linked docs below.

Use [../catalog-theme/](../catalog-theme/) when you need the commerce catalog rules. Prefer **this folder** when authoring or reviewing an Informatic pack.
